# monitor-theme-paper

Paper 纸感主题 —— 专为 [monitor](https://github.com/monitor-probe) 打造的现代质感状态监控面板。

## 特色

- **质感纸面视觉**：低饱和莫兰迪调色，温润不刺眼，原生支持明暗双色。
- **PC 视口一页式**：左右分栏独立滚动，导航/搜索/汇总顶栏常驻，告别整页多层嵌套滚动条。
- **资源与网络双页签**：详情页将系统资源走势（CPU/内存自适应量程）与网络带宽/延迟独立分离。
- **24 小时可用率轨迹**：平滑柱条展示过去 24 小时在线健康度，支持触摸/鼠标滑动准星跟手读数。
- **削峰平滑与智能重连**：内置 MAD 中位数滤波平滑与指数渐进退避断线重连（带倒计时反馈）。
- **多强调色切换**：后台支持一键切换经典蓝、翡翠绿、琥珀橙、暮光紫、极简黑灰、玫瑰赤。
- **纯原生单文件**：零外部构建依赖，单 HTML + Canvas 高效直出。

## 安装

在 monitor 管理后台「主题」页面：
1. 填入 GitHub 仓库地址 `https://github.com/3922510-creator/monitor-theme-paper`
2. 点击「从 GitHub 安装」即可一键启用。

## 源码与开发构建

本项目遵循 Web 原生标准（Vanilla HTML5 / CSS3 / ES2022），不引入庞大的前端框架或黑盒编译流：

- **源码目录**：`src/index.html`（完整未压缩原生源码，包含所有交互、样式与渲染逻辑）
- **语法校验**：`npm run check`（核对配置一致性、必要文件与 JS 语法）
- **构建输出**：`npm run build`（同步输出至 `dist/index.html` 并打包为可供 hub 部署的 `theme.tar.gz`）
